# 项目技术栈

> 本文件集中管理技术栈信息。各角色提示词引用此文件，不在各自提示词中硬编码。

> 新项目请根据实际情况修改本文件。

## 后端

- 语言：Python 3.11+
- 异步框架：asyncio + async/await
- 类型校验：Pydantic V2
- 日志：loguru（禁止 print）
- HTTP 客户端：httpx
- 测试：pytest + pytest-asyncio

## 前端

- 框架：Vue 3 + TypeScript
- 组件库：Ant Design Vue 4（a- 前缀）
- 构建工具：Vite
- 状态管理：Pinia

## 基础设施

- 容器：Docker + docker-compose
- 数据库：按项目实际情况（启动时读取配置文件确认）
- CI/CD：按项目实际情况

## 协作工具

- 任务管理：GitHub Issue + Label（通过 `gh` CLI）
- 版本控制：Git

## 命名规范

- 文件/变量/函数：snake_case
- 类：PascalCase
- 常量：UPPER_SNAKE_CASE
