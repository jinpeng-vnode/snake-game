# UI 优化与地图扩展 - 任务总览

## 📋 PRD 文档

**文档路径：** `docs/产品/L1-TASK-007-UI优化与地图扩展-PRD.md`

**核心需求：**
1. **地图扩展**：从 20×20 扩大到 30×30（400×400px → 600×600px）
2. **UI 现代化**：渐变色彩、动画效果、视觉反馈

**关键特性：**
- 渐变背景（深蓝到深紫）
- 蛇身渐变（亮绿到深绿）+ 蛇头高光
- 食物呼吸动画（缩放循环）
- 吃食物粒子特效（扩散淡出）
- 分数面板美化（卡片样式 + 渐变文字 + emoji）
- 开始/结束界面美化（渐变文字 + 按钮样式 + 淡入动画）

- **优先级：** P0
- **负责角色：** 前端开发

### Issue #9: 核心 UI 优化开发
- **优先级：** P0
- **负责角色：** 前端开发
- **预估工作量：** 1 天
- **依赖：** #8（地图扩展）
- **文档：** `docs/issues/Issue-009-核心UI优化开发.md`

**核心任务：**
- 渐变背景 + 虚线网格
- 蛇身渐变色 + 蛇头高光
- 分数面板美化（卡片样式 + 渐变文字 + emoji）
- 开始/结束界面美化（渐变文字 + 按钮样式）

**关键代码修改：**
- `Renderer.drawBackground()` - 径向渐变 + 虚线网格
- `Renderer.drawSnake()` - 动态计算渐变色 + 高光
- `Renderer.drawReadyScreen()` - 渐变标题 + 按钮样式
- `Renderer.drawGameOverScreen()` - 渐变遮罩 + 渐变文字
- CSS - 分数面板卡片样式 + 文字渐变

---

### Issue #10: 动画特效开发
- **优先级：** P1
- **负责角色：** 前端开发
- **预估工作量：** 1.5 天
- **依赖：** #9（核心 UI 优化）
- **文档：** `docs/issues/Issue-010-动画特效开发.md`

**核心任务：**
- 新增 `ParticleSystem` 模块（粒子管理）
- 食物呼吸动画（基于时间戳的缩放）
- 吃食物粒子特效（6-8 个粒子扩散淡出）
- 游戏结束界面淡入动画（透明度 0 → 1）

**关键代码修改：**
- 新增 `ParticleSystem` 模块（spawn/update/render/clear）
- `Renderer.drawFood()` - 添加 `timestamp` 参数，计算动画半径
- `Game.startRenderLoop()` - 使用 `requestAnimationFrame` 处理动画
- `Game.tick()` - 吃食物时调用 `ParticleSystem.spawn()`
- `Game.render()` - 渲染粒子系统
