# 01-贪吃蛇核心功能 测试用例

> 模块：贪吃蛇游戏全部功能 | 优先级：P1 | 用例数：32
> 对应任务：#4 L2 TASK-003、#6 L3 TASK-005
> 测试方式：手动测试（浏览器中双击 index.html）

---

## 测试环境

- 浏览器：Chrome / Firefox / Safari / Edge 最新版
- 打开方式：双击 index.html（file:// 协议）
- 前置操作：清除 localStorage（DevTools → Application → Local Storage → 删除 snakeHighScore）
