# L1-TASK-001 贪吃蛇游戏 产品需求文档（PRD）

## 1. 项目概述

### 1.1 项目背景

用户需要一个基于浏览器的经典贪吃蛇游戏，纯前端实现，无需后端服务。通过 HTML + Canvas + JavaScript 技术栈，实现可直接在浏览器中打开运行的轻量级小游戏。

### 1.2 项目目标

- 实现一个功能完整的经典贪吃蛇游戏
- 游戏可通过直接打开 index.html 运行，无需构建工具或服务器
- 支持分数记录和最高分持久化
- 界面简洁美观，交互流畅

### 1.3 目标用户

休闲游戏玩家，希望在浏览器中快速体验经典贪吃蛇游戏的用户。无年龄限制，无需注册登录。

### 1.4 使用场景

1. 用户在工作间隙打开浏览器，双击 index.html 文件即可开始游戏放松
2. 用户想挑战自己的最高分记录，反复游玩并查看历史最高分
3. 用户分享 HTML 文件给朋友，朋友无需安装任何软件即可游玩

## 2. 功能范围

### 2.1 功能清单

| 功能模块 | 功能点 | 优先级 | 说明 |
|----------|--------|--------|------|
| 游戏核心 | 蛇的移动 | P0 | 蛇自动向当前方向移动，每 200ms 移动一格 |
| 游戏核心 | 方向控制 | P0 | 键盘方向键（↑↓←→）控制蛇的移动方向 |
| 游戏核心 | 禁止掉头 | P0 | 蛇不能直接反向移动（如向右时不能直接按左） |
| 游戏核心 | 食物生成 | P0 | 食物随机出现在空白网格上，不与蛇身重叠 |
| 游戏核心 | 吃食物 | P0 | 蛇头碰到食物时，蛇身长度 +1，分数 +10 |
| 碰撞检测 | 墙壁碰撞 | P0 | 蛇头碰到画布边界时游戏结束 |
| 碰撞检测 | 自身碰撞 | P0 | 蛇头碰到自身时游戏结束 |
| 分数系统 | 当前分数 | P0 | 实时显示当前游戏分数 |
| 分数系统 | 最高分 | P1 | 使用 localStorage 持久化存储最高分，刷新页面后保留 |
| 游戏状态 | 开始界面 | P1 | 显示游戏标题和开始按钮，支持点击按钮或按空格键开始 |
| 游戏状态 | 游戏结束界面 | P1 | 显示最终分数、最高分和重新开始按钮 |
| 游戏状态 | 重新开始 | P1 | 游戏结束后可重新开始，重置游戏状态 |

### 2.2 不做的事情（Out of Scope）

- 不做移动端触屏控制
- 不做多人对战模式
- 不做难度选择（速度固定）
- 不做音效和背景音乐
- 不做排行榜（仅本地最高分）
- 不做暂停/继续功能
- 不做蛇身皮肤切换


## 3. 页面与交互设计

### 3.1 页面清单

| 页面名称 | 入口 | 核心功能 |
|----------|------|----------|
| 游戏主界面 | 直接打开 index.html | 包含所有游戏状态：开始、游戏中、游戏结束 |

本游戏为单页面应用，所有状态在同一个页面内切换。

### 3.2 页面详细描述

#### 3.2.1 游戏主界面

**页面整体布局：**
- 页面背景色覆盖全屏，游戏区域居中显示
- 从上到下依次为：分数面板 → 游戏画布 → （无底部元素）

**页面元素：**

| 元素 | 类型 | 位置 | 说明 |
|------|------|------|------|
| 游戏画布 | Canvas | 页面水平居中 | 400×400px，20×20 网格（每格 20px），显示蛇和食物 |
| 分数显示 | 文本 | 画布上方左侧 | 格式："分数: {N}"，初始为 0，字号 20px |
| 最高分显示 | 文本 | 画布上方右侧 | 格式："最高分: {N}"，从 localStorage 读取，字号 20px |
| 游戏标题 | 文本 | 画布中央偏上 | "贪吃蛇"，字号 48px，仅开始界面显示 |
| 开始按钮 | 按钮/文本 | 画布中央 | "按空格键开始游戏"，字号 20px，仅开始界面显示 |
| 游戏结束遮罩 | 半透明层 | 覆盖整个画布 | 黑色半透明背景 rgba(0,0,0,0.5)，仅游戏结束时显示 |
| 游戏结束标题 | 文本 | 遮罩层中央偏上 | "游戏结束"，字号 36px，白色 |
| 最终分数 | 文本 | 遮罩层中央 | "最终分数: {N}"，字号 24px，白色 |
| 重新开始提示 | 文本 | 遮罩层中央偏下 | "按空格键重新开始"，字号 18px，白色 |

**按钮行为：**

| 按钮/操作 | 触发条件 | 点击/按键后行为 | 成功反馈 | 失败反馈 |
|-----------|----------|----------------|----------|----------|
| 空格键（开始） | 游戏处于开始界面状态 | 隐藏标题和提示文字，蛇从画布中央开始向右移动，分数归零 | 游戏画面开始刷新，蛇开始移动 | 无 |
| 空格键（重新开始） | 游戏处于结束状态 | 清除遮罩层，重新初始化蛇的位置和长度，重新生成食物，分数归零 | 游戏重新开始 | 无 |
| 方向键 ↑ | 游戏进行中，蛇当前方向不是向下 | 蛇的移动方向变为向上 | 蛇在下一帧向上移动 | 如果当前方向是向下，忽略此操作 |
| 方向键 ↓ | 游戏进行中，蛇当前方向不是向上 | 蛇的移动方向变为向下 | 蛇在下一帧向下移动 | 如果当前方向是向上，忽略此操作 |
| 方向键 ← | 游戏进行中，蛇当前方向不是向右 | 蛇的移动方向变为向左 | 蛇在下一帧向左移动 | 如果当前方向是向右，忽略此操作 |
| 方向键 → | 游戏进行中，蛇当前方向不是向左 | 蛇的移动方向变为向右 | 蛇在下一帧向右移动 | 如果当前方向是向左，忽略此操作 |

**页面状态：**

- **开始界面状态：** 画布显示网格背景，中央显示"贪吃蛇"标题和"按空格键开始游戏"提示。分数面板显示"分数: 0"和"最高分: {历史最高分}"。无蛇和食物。
- **游戏进行中状态：** 标题和提示文字消失。蛇在画布中移动，食物显示在随机位置。分数面板实时更新当前分数。
- **游戏结束状态：** 画布上覆盖半透明黑色遮罩，显示"游戏结束"、最终分数和"按空格键重新开始"。如果本次分数超过最高分，最高分面板同步更新。


## 4. 用户流程

### 4.1 核心流程

#### 4.1.1 开始游戏流程

```
1. 用户在浏览器中打开 index.html
2. 页面显示游戏画布，画布中央显示"贪吃蛇"标题和"按空格键开始游戏"提示
3. 分数面板显示"分数: 0"和"最高分: {N}"（N 从 localStorage 读取，首次为 0）
4. 用户按下空格键
5. 标题和提示文字消失
6. 蛇出现在画布中央，初始长度 3 格，方向向右
7. 食物随机出现在画布空白网格上（红色圆形）
8. 蛇开始自动向右移动，速度为每 200ms 移动一格
```

#### 4.1.2 游戏进行流程

```
1. 蛇按当前方向自动移动，每 200ms 前进一格
2. 用户按方向键改变蛇的移动方向
3. 每次移动后，系统检测蛇头位置：
   a. 蛇头碰到食物 → 执行"吃食物"逻辑
   b. 蛇头碰到墙壁 → 执行"游戏结束"逻辑
   c. 蛇头碰到自身 → 执行"游戏结束"逻辑
   d. 以上都没有 → 蛇正常前进（尾部缩短一格，头部延伸一格）
```

**吃食物逻辑：**
1. 蛇身长度 +1（本次移动尾部不缩短）
2. 分数 +10，分数面板实时更新
3. 如果当前分数 > 最高分，更新最高分并写入 localStorage
4. 在画布空白网格上随机生成新食物（不与蛇身任何部分重叠）

**判断分支：**
- 如果蛇头碰到食物 → 蛇身长度 +1，分数 +10，新食物随机生成
- 如果蛇头碰到墙壁（x < 0 或 x >= 20 或 y < 0 或 y >= 20）→ 游戏结束
- 如果蛇头碰到自身（蛇头坐标与蛇身任意节点坐标重合）→ 游戏结束
- 如果用户按了反方向键（如正在向右时按左）→ 忽略该操作，方向不变

**异常流程：**
- 快速连续按键：每个游戏帧只处理一次方向变更，防止在一帧内多次改变方向导致蛇掉头
- 游戏刚开始就撞墙：蛇初始位置在画布中央，初始方向向右，距离右墙有足够距离，不会立即撞墙

#### 4.1.3 游戏结束流程

```
1. 检测到碰撞（墙壁或自身）
2. 游戏循环停止，蛇停止移动
3. 画布上覆盖半透明黑色遮罩
4. 遮罩层显示"游戏结束"标题
5. 显示"最终分数: {N}"
6. 显示"按空格键重新开始"提示
7. 如果本次分数 > 历史最高分，更新 localStorage 中的最高分
```

#### 4.1.4 重新开始流程

```
1. 游戏处于结束状态
2. 用户按下空格键
3. 清除遮罩层和结束界面文字
4. 蛇重置到画布中央，长度 3 格，方向向右
5. 分数重置为 0
6. 食物重新随机生成
7. 游戏循环重新启动，蛇开始移动
```

## 5. 数据需求

### 5.1 需要持久化的数据

| 数据项 | 说明 | 存储方式 |
|--------|------|----------|
| 最高分 | 历史最高游戏分数 | localStorage，key 为 "snakeHighScore" |

### 5.2 数据展示规则

- 当前分数：整数，从 0 开始，每吃一个食物 +10，实时更新显示
- 最高分：整数，页面加载时从 localStorage 读取，游戏中如果当前分数超过最高分则实时更新
- 如果 localStorage 不可用（如隐私模式），最高分默认为 0，不报错，游戏正常运行

## 6. 非功能需求

- 性能：游戏帧率稳定，蛇移动无卡顿（200ms 间隔的定时器准确执行）
- 兼容性：支持 Chrome、Firefox、Safari、Edge 最新版本
- 响应式：游戏画布固定 400×400px，页面居中显示，最小支持宽度 480px
- 无依赖：不使用任何第三方库，纯原生 HTML + CSS + JavaScript
- 可访问性：页面 title 设置为"贪吃蛇游戏"
