# L1-TASK-007 贪吃蛇游戏 UI 优化与地图扩展 产品需求文档（PRD）

## 1. 项目概述

### 1.1 需求背景

当前贪吃蛇游戏已实现基础功能，但界面较为简单，游戏空间有限。为提升用户体验和游戏可玩性，需要对 UI 进行现代化升级，并扩大游戏地图。

### 1.2 项目目标

- **UI 现代化**：采用渐变色彩、动画效果、视觉反馈，提升游戏美观度和沉浸感
- **地图扩展**：将游戏地图从 20×20 扩大到 30×30，增加游戏挑战性和可玩时长
- **保持兼容**：确保游戏仍可通过浏览器直接打开运行，无需额外依赖

### 1.3 目标用户

现有贪吃蛇游戏玩家，希望获得更精美的视觉体验和更大的游戏空间。

### 1.4 使用场景

1. 用户打开游戏，看到现代化的渐变背景和精美的开始界面，感受到游戏品质提升
2. 用户在更大的地图上游玩，有更多操作空间和策略选择
3. 用户吃到食物时看到动画反馈，获得更强的成就感

## 3. 详细设计

### 3.1 地图扩展规格

| 参数 | 原值 | 新值 | 说明 |
|------|------|------|------|
| 画布尺寸 | 400×400px | 600×600px | 扩大 1.5 倍 |
| 网格数量 | 20×20 | 30×30 | 扩大 1.5 倍 |
| 单格尺寸 | 20px | 20px | 保持不变，确保视觉清晰 |
| 蛇初始位置 | (10,10) | (15,15) | 居中位置 |
| 蛇初始长度 | 3 格 | 3 格 | 保持不变 |
| 游戏速度 | 200ms/格 | 180ms/格（可选） | 可根据测试调整 |

**技术实现要点：**
- 修改常量 `CANVAS_SIZE = 600`，`GRID_COUNT = 30`
- 修改 `Snake.init()` 中蛇头初始坐标为 `(15, 15)`
- 修改 HTML/CSS 确保页面居中和响应式布局
- 可选：修改 `TICK_INTERVAL = 180` 提升流畅度

### 3.2 UI 优化规格

#### 3.2.1 渐变背景

**当前：** 纯色背景 `#1a1a2e` + 网格线 `#16213e`

**优化后：**
- 背景：径向渐变，从中心 `#1a1a2e`（深蓝灰）到边缘 `#0f0f23`（深紫黑）
- 网格线：虚线样式，颜色 `rgba(255, 255, 255, 0.05)`，降低视觉干扰
- 实现：`ctx.createRadialGradient()` + `ctx.setLineDash([2, 4])`

#### 3.2.2 蛇身渐变

**当前：** 蛇头 `#388E3C`（深绿），蛇身 `#4CAF50`（亮绿）

**优化后：**
- 蛇头到蛇尾渐变：从 `#00ff88`（亮青绿）到 `#00aa44`（深绿）
- 每个蛇身段根据索引计算颜色：`color = lerp(headColor, tailColor, index / length)`
- 蛇头添加高光效果：内部绘制小圆形 `rgba(255, 255, 255, 0.3)`
- 实现：动态计算每段颜色，使用 HSL 或 RGB 插值

#### 3.2.3 食物动画

**当前：** 静态红色圆形 `#F44336`，直径 16px

**优化后：**
- 颜色：渐变填充，从中心 `#ff6b6b`（亮红）到边缘 `#ee5a52`（深红）
- 动画：缩放呼吸效果，半径在 6px - 10px 之间循环（周期 1 秒）
- 实现：`radius = 8 + 2 * Math.sin(timestamp / 500)`，使用 `requestAnimationFrame` 或时间戳计算

#### 3.2.4 吃食物特效

**效果：** 吃到食物瞬间，在食物位置生成 6-8 个小圆点，向外扩散并淡出（持续 300ms）

**实现：**
- 粒子数据结构：`{ x, y, vx, vy, alpha, life }`
- 初始速度：随机方向，速度 2-4 px/frame
- 每帧更新：位置 += 速度，透明度递减，生命周期递减
- 颜色：与食物颜色一致 `#ff6b6b`
- 渲染：在 `Renderer.render()` 中绘制所有活跃粒子

#### 3.2.5 分数面板美化

**当前：** 纯文本，白色，20px Arial

**优化后：**
- 背景：半透明卡片 `rgba(255, 255, 255, 0.1)`，圆角 8px，内边距 12px
- 文字：渐变色，从 `#00ff88` 到 `#00d4ff`（青绿到青蓝）
- 图标：分数前添加 "🏆" emoji，最高分前添加 "⭐" emoji
- 字体：加粗，字号 22px
- 实现：修改 HTML/CSS，使用 `linear-gradient` 和 `background-clip: text`

#### 3.2.6 开始/结束界面美化

**当前：** 纯文本 + 半透明黑色遮罩

**优化后：**

**开始界面：**
- 标题 "贪吃蛇"：渐变文字（`#00ff88` → `#00d4ff`），字号 64px，添加阴影
- 副标题：添加 "SNAKE GAME" 英文副标题，字号 20px，透明度 0.8
- 提示文字：改为按钮样式，背景 `rgba(0, 255, 136, 0.2)`，边框 2px 实线，圆角 8px，内边距 12px 24px
- 装饰：标题上方添加蛇头图标（绘制简化蛇头形状）

**结束界面：**
- 遮罩：从纯黑改为渐变 `rgba(0, 0, 0, 0.7)` 到 `rgba(26, 26, 46, 0.9)`
- 标题 "游戏结束"：渐变文字，字号 48px
- 分数显示：数字部分放大并高亮（渐变色）
- 重新开始按钮：同开始界面按钮样式
- 动画：界面淡入效果（透明度 0 → 1，持续 300ms）

### 3.3 页面布局调整

**当前布局：**
```
分数面板（400px 宽）
游戏画布（400×400px）
```

**优化后布局：**
```
分数面板（600px 宽，卡片样式）
游戏画布（600×600px）
```

**响应式处理：**
- 最小支持宽度从 480px 调整到 680px（600px 画布 + 40px 左右边距）
- 小屏幕（< 680px）时，画布缩放到 90% 宽度，保持纵横比
- 实现：CSS `max-width: 90vw` + `aspect-ratio: 1/1`

## 5. 用户流程（变更部分）

### 5.1 开始游戏流程（变更）

```
1. 用户打开 index.html
2. 页面显示 600×600px 游戏画布，背景为深色渐变
3. 画布中央显示渐变标题 "贪吃蛇" + 副标题 "SNAKE GAME"
4. 显示按钮样式的 "按空格键开始游戏" 提示
5. 分数面板显示卡片样式的分数和最高分（带图标和渐变文字）
6. 用户按空格键
7. 蛇出现在 (15, 15)，初始长度 3 格，蛇身为渐变色
8. 食物出现，带有呼吸动画
9. 蛇开始移动
```

### 5.2 游戏进行流程（变更）

```
（基础流程不变）

吃食物逻辑（新增特效）：
1. 蛇头碰到食物
2. 触发粒子特效：6-8 个小圆点从食物位置向外扩散
3. 蛇身长度 +1，分数 +10
4. 分数面板更新（渐变数字）
5. 新食物生成（带呼吸动画）
```

### 5.3 游戏结束流程（变更）

```
1. 检测到碰撞
2. 游戏循环停止
3. 渐变遮罩淡入（300ms）
4. 显示渐变标题 "游戏结束"
5. 显示最终分数（数字高亮）
6. 显示按钮样式的 "按空格键重新开始"
```

## 7. 风险与注意事项

### 7.1 性能风险

- **风险**：粒子特效和动画可能影响低端设备性能
- **缓解**：限制粒子数量（最多 8 个），粒子生命周期短（300ms），使用 `requestAnimationFrame` 优化渲染

### 7.2 兼容性风险

- **风险**：CSS 渐变文字（`background-clip: text`）在旧版浏览器可能不支持
- **缓解**：提供降级方案（纯色文字），不影响核心功能

### 7.3 响应式风险

- **风险**：600px 画布在小屏幕上可能显示不全
- **缓解**：CSS 媒体查询 + `max-width: 90vw` 自动缩放
