# L1-TASK-001 贪吃蛇 v3 产品需求文档（PRD）

> 合并需求来源：#27 手机版支持、#28 音效系统、#29 食物种类、#30 体验优化

## 1. 项目概述

### 1.1 项目背景
当前贪吃蛇游戏为纯 PC 端 HTML5 Canvas 游戏（game.js + index.html），仅支持键盘操控，无音效反馈，食物种类单一，且已有的粒子特效模块（ParticleSystem）未接入主流程。本次迭代目标是将游戏升级为手机端可玩、体验丰富的版本。

### 1.2 项目目标
- 手机浏览器可正常游玩，触屏操控流畅
- 音效系统完整，吃食物/游戏结束有音效，支持背景音乐和静音控制
- 食物种类丰富，有特殊效果和限时机制
- 体验细节完善：暂停功能、粒子特效、WASD 键位、墙壁视觉提示
- PC 端原有功能不受影响

### 1.3 目标用户
- 手机用户：通过手机浏览器访问游戏的休闲玩家
- PC 用户：原有键盘操控用户，体验不降级

### 1.4 使用场景
1. 通勤/碎片时间：用户在手机浏览器打开游戏，用触屏滑动或虚拟方向键操控
2. PC 休闲：用户用键盘（方向键或 WASD）操控，享受音效和粒子特效
3. 安静环境：用户一键静音，关闭所有音效和背景音乐

## 4. 用户流程

### 4.1 核心流程

#### 4.1.1 手机端开始游戏流程
1. 用户在手机浏览器打开 index.html
2. 页面自适应手机屏幕宽度，画布占满可用宽度（保持正方形）
3. 画布下方显示虚拟方向键
4. 用户点击画布或按虚拟方向键任意键
5. 游戏开始，蛇从画布中央出现，背景音乐开始播放（如未静音）
6. 用户通过滑动画布或点击虚拟方向键控制蛇移动

**判断分支：**
- 如果用户之前设置过静音 → 读取 localStorage，保持静音状态
- 如果屏幕宽度 < 768px → 显示虚拟方向键
- 如果屏幕宽度 ≥ 768px → 隐藏虚拟方向键

#### 4.1.2 吃食物流程
1. 蛇头移动到食物所在格子
2. 系统判断食物类型
3. 播放吃食物音效（如未静音）
4. 触发粒子特效（在食物位置生成粒子爆散效果）
5. 根据食物类型执行效果：
   - 普通食物：蛇身 +1，加对应分值
   - 加速食物：蛇身 +1，加分，游戏速度临时加快
   - 减速食物：蛇身 +1，加分，游戏速度临时减慢
   - 双倍得分食物：蛇身 +1，加分，一段时间内得分翻倍
   - 缩短食物：蛇身 -2（最短保持长度 1），加分
6. 分数更新显示
7. 如有特殊效果，画布上方显示效果状态指示和倒计时
8. 生成新食物（随机类型，特殊食物有出现概率限制）

**异常流程：**
- 缩短食物导致蛇身长度不足：蛇身最短保持 1 节（蛇头），不会缩到消失
- 多个特殊效果叠加：同类效果刷新持续时间，不同类效果可共存

#### 4.1.3 特殊食物限时流程
1. 特殊食物生成后开始倒计时（如 8 秒）
2. 倒计时期间食物正常显示，最后 3 秒闪烁提示即将消失
3. 倒计时结束，食物消失
4. 系统在下一个普通食物被吃掉后，按概率决定是否生成新的特殊食物

#### 4.1.4 暂停/恢复流程
1. 游戏进行中，用户按 ESC 或 P 键
2. 游戏循环暂停（clearInterval），渲染循环继续
3. 画布显示半透明遮罩 + "已暂停" 文字
4. 特殊食物倒计时暂停
5. 特殊效果持续时间暂停
6. 用户按 ESC/P/空格恢复
7. 游戏循环恢复（setInterval），倒计时继续

**异常流程：**
- 手机端暂停：点击画布上的暂停区域或使用虚拟按键（暂停按钮在控制栏）
- 页面失焦（切换标签页/切换 App）：自动暂停游戏

#### 4.1.5 音效控制流程
1. 游戏启动时读取 localStorage 中的静音状态
2. 默认非静音
3. 用户点击静音按钮 → 切换静音状态 → 图标变化 → 状态写入 localStorage
4. 静音时：所有音效和背景音乐静音
5. 取消静音时：恢复音效，背景音乐从当前位置继续播放

## 5. 数据需求

### 5.1 食物类型定义

| 食物类型 | 颜色 | 形状 | 分值 | 效果 | 持续时间 | 出现概率 | 限时 |
|----------|------|------|------|------|----------|----------|------|
| 普通食物 | 红色 | 圆形 | 10 分 | 蛇身 +1 | — | 100%（保底） | 不消失 |
| 加速食物 | 橙色 | 菱形 | 15 分 | 蛇身 +1，速度 ×1.3 | 5 秒 | 15% | 8 秒后消失 |
| 减速食物 | 蓝色 | 三角形 | 15 分 | 蛇身 +1，速度 ×0.7 | 5 秒 | 15% | 8 秒后消失 |
| 双倍得分 | 金色 | 星形 | 20 分 | 蛇身 +1，得分 ×2 | 8 秒 | 10% | 8 秒后消失 |
| 缩短食物 | 紫色 | 方形 | 5 分 | 蛇身 -2（最短 1） | — | 10% | 6 秒后消失 |

> 场上始终有且仅有 1 个食物。普通食物被吃掉后，按上述概率随机决定下一个食物类型。特殊食物消失后自动生成一个普通食物。

### 5.2 需要持久化的数据
| 数据项 | 说明 | 存储方式 |
|--------|------|----------|
| 最高分 | 历史最高分 | localStorage（已有） |
| 静音状态 | 是否静音 | localStorage |

### 5.3 音效资源
| 音效 | 说明 | 实现方式 |
|------|------|----------|
| 吃食物音效 | 短促清脆的音效 | Web Audio API 程序化生成（不依赖外部音频文件） |
| 游戏结束音效 | 低沉的失败音效 | Web Audio API 程序化生成 |
| 背景音乐 | 轻快的循环旋律 | Web Audio API 程序化生成 |

> 所有音效通过 Web Audio API 程序化生成，不引入外部音频文件，保持纯前端单文件架构。

## 6. 非功能需求
- 性能：游戏帧率保持 60fps，tick 间隔 180ms 不变（加速/减速时临时调整）
- 兼容性：Chrome/Safari/Firefox 最新版，iOS Safari、Android Chrome
- 响应式：最小支持宽度 320px（iPhone SE），画布和虚拟方向键自适应
- 触屏延迟：滑动响应 < 100ms
- 音频：首次用户交互后才初始化 AudioContext（遵循浏览器自动播放策略）
- 架构：保持单文件 game.js + index.html 结构，不拆分文件
