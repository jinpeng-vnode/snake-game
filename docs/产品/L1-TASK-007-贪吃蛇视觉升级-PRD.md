# L1-TASK-007 贪吃蛇视觉升级 产品需求文档（PRD）

## 1. 项目概述

### 1.1 项目背景

当前贪吃蛇游戏功能完整，但视觉体验存在以下问题：
1. **画布太小**：400×400px 在现代大屏幕上只占屏幕中央一小块，视觉冲击力不足
2. **蛇的造型生硬**：纯方块填充，缺乏可爱感和辨识度
3. **整体风格单调**：深色背景 + 纯色方块，缺少层次感和精致感

用户希望游戏"更好看"、"画布更大"、"蛇更 Q 弹可爱"。

### 1.2 项目目标

- 游戏画布自适应屏幕大小，充分利用可视区域
- 蛇的造型从方块升级为圆润 Q 弹风格，具有可爱感
- 整体视觉风格统一升级，提升精致感和沉浸感
- 不改变任何游戏逻辑（移动、碰撞、计分规则不变）

### 1.3 目标用户

同原 PRD，休闲游戏玩家。本次升级提升视觉体验，不改变目标用户群。

### 1.4 使用场景

同原 PRD，新增：
- 用户在大屏显示器上游玩时，游戏画面能充分利用屏幕空间，不再显得"小小的一点点"

## 2. 功能范围

### 2.1 功能清单

| 功能模块 | 功能点 | 优先级 | 说明 |
|----------|--------|--------|------|
| 画布自适应 | 响应式画布尺寸 | P0 | 画布根据窗口大小自适应，最大不超过视口 80%，最小 400px |
| 蛇造型升级 | Q 弹圆润蛇身 | P0 | 蛇身每节为圆角矩形或圆形，节与节之间平滑连接 |
| 蛇造型升级 | 蛇头表情 | P1 | 蛇头绘制两个小眼睛，朝向移动方向 |
| 蛇造型升级 | 蛇身渐变色 | P1 | 蛇身从头到尾颜色渐变（头部鲜艳，尾部渐淡） |
| 食物升级 | 食物样式美化 | P1 | 食物改为苹果样式（红色圆形 + 小叶子），带轻微光泽效果 |
| 背景升级 | 网格背景美化 | P1 | 棋盘格交替色背景，替代纯色 + 网格线 |
| UI 升级 | 分数面板美化 | P2 | 分数面板字体和样式升级，与整体风格统一 |
| UI 升级 | 游戏结束界面美化 | P2 | 结束遮罩层视觉升级，文字排版更精致 |

### 2.2 不做的事情（Out of Scope）

- 不做蛇身移动动画（帧间插值平滑移动），保持逐格跳跃
- 不做粒子特效（吃食物爆炸效果等）
- 不做音效
- 不做皮肤切换系统
- 不改变游戏逻辑（速度、计分、碰撞规则不变）

## 3. 页面与交互设计

### 3.1 页面清单

同原 PRD，仍为单页面。本次仅升级视觉表现，不新增页面。

### 3.2 页面详细描述

#### 3.2.1 画布自适应规则

| 属性 | 旧值 | 新值 |
|------|------|------|
| 画布尺寸 | 固定 400×400px | 自适应：`min(视口宽度 × 0.8, 视口高度 × 0.7, 800px)`，向下取整到网格整数倍 |
| 网格数量 | 固定 20×20 | 固定 20×20（不变） |
| 每格像素 | 固定 20px | 动态计算：画布尺寸 ÷ 20 |
| 最小画布 | 无 | 400×400px（每格最小 20px） |
| 最大画布 | 无 | 800×800px（每格最大 40px） |
| 窗口缩放 | 不响应 | 监听 resize 事件，实时调整画布大小（游戏进行中也生效） |

#### 3.2.2 蛇的视觉规格

**蛇头：**
- 形状：圆角矩形，圆角半径为格子大小的 40%
- 颜色：#4CAF50（主绿色）
- 眼睛：两个白色小圆（直径为格子大小的 20%），内有黑色瞳孔（直径为格子大小的 10%）
- 眼睛位置：根据蛇的移动方向动态调整，始终朝向前方
  - 向右：眼睛在蛇头右半部分，上下排列
  - 向左：眼睛在蛇头左半部分，上下排列
  - 向上：眼睛在蛇头上半部分，左右排列
  - 向下：眼睛在蛇头下半部分，左右排列

**蛇身：**
- 形状：圆角矩形，圆角半径为格子大小的 35%
- 颜色渐变：从头到尾，色相保持绿色，饱和度和亮度逐渐降低
  - 第 1 节（紧接蛇头）：#4CAF50
  - 最后一节：#81C784（浅绿）
  - 中间节点线性插值
- 每节之间留 1-2px 间隙，形成"一节一节"的 Q 弹感

**蛇尾：**
- 最后一节略小（缩小到格子大小的 80%），居中绘制，形成收尾效果

#### 3.2.3 食物视觉规格

- 主体：红色圆形（#F44336），直径为格子大小的 75%
- 高光：左上角一个白色小圆弧，模拟光泽感（半透明白色，rgba(255,255,255,0.3)）
- 叶子：顶部偏右一个小绿色椭圆（#4CAF50），模拟苹果叶子
- 茎：顶部一条短棕色线段（#795548）

#### 3.2.4 背景视觉规格

- 棋盘格交替色：
  - 浅色格：#1a1a2e（当前背景色）
  - 深色格：#16162a（略深一点）
- 两种颜色交替排列，形成棋盘格效果
- 不再绘制网格线

#### 3.2.5 分数面板视觉规格

| 属性 | 旧值 | 新值 |
|------|------|------|
| 字体 | Arial 20px | "Segoe UI", Arial, sans-serif，大小随画布等比缩放 |
| 分数颜色 | #ffffff | #FFD700（金色） |
| 最高分颜色 | #ffffff | #B0BEC5（银灰色） |
| 面板宽度 | 固定 400px | 与画布同宽 |

#### 3.2.6 游戏结束界面视觉规格

- 遮罩：rgba(0, 0, 0, 0.6)（略加深）
- "游戏结束"标题：字号为画布宽度的 9%，白色，加粗
- 最终分数：字号为画布宽度的 6%，#FFD700 金色
- 重新开始提示：字号为画布宽度的 4.5%，rgba(255,255,255,0.7) 半透明白色
- 各文字行间距合理，整体居中

#### 3.2.7 开始界面视觉规格

- "贪吃蛇"标题：字号为画布宽度的 12%，白色，加粗
- 开始提示：字号为画布宽度的 5%，rgba(255,255,255,0.7)

**页面状态：** 同原 PRD，仅视觉表现升级，状态切换逻辑不变。

## 4. 用户流程

同原 PRD，所有用户流程不变。本次仅升级视觉表现。

同原 PRD，无新增数据需求。

- [ ] 画布大小随窗口自适应，大屏幕上明显比原来大
- [ ] 画布最小 400×400px，最大 800×800px
- [ ] 窗口缩放时画布实时调整，游戏不中断
- [ ] 蛇头为圆角矩形，带两个朝向移动方向的小眼睛
- [ ] 蛇身为圆角矩形，从头到尾颜色渐变（深绿→浅绿）
- [ ] 蛇身各节之间有间隙，呈现 Q 弹分节感
- [ ] 蛇尾略小，有收尾效果
- [ ] 食物为苹果样式（红色圆形 + 高光 + 叶子 + 茎）
- [ ] 背景为棋盘格交替色，无网格线
- [ ] 分数面板字体和颜色升级（金色分数、银灰最高分）
- [ ] 分数面板宽度与画布同宽
- [ ] 游戏结束界面文字大小随画布等比缩放
- [ ] 所有游戏逻辑不变（移动、碰撞、计分、方向控制）
- [ ] 无第三方依赖，纯原生实现
