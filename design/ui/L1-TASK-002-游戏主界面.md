# L1-TASK-002 游戏主界面 UI 规格

## 一、页面信息

- 路由：无（直接打开 `index.html`）
- 文件：`index.html`（单文件，包含 HTML + CSS + JavaScript）
- 权限：无需登录，无需服务器
- 页面 title：`贪吃蛇游戏`

## 二、页面整体布局

```
+----------------------------------------------------+
|                   页面背景 #0f0f23                    |
|                                                      |
|            +------------------------------+          |
|            |        分数面板 (HTML)         |          |
|            |  分数: 0            最高分: 0  |          |
|            +------------------------------+          |
|            |                              |          |
|            |                              |          |
|            |      游戏画布 (Canvas)        |          |
|            |        400 × 400px           |          |
|            |                              |          |
|            |                              |          |
|            +------------------------------+          |
|                                                      |
+----------------------------------------------------+
```

### 布局规格

| 属性 | 值 | 说明 |
|------|-----|------|
| 页面背景色 | `#0f0f23` | 深蓝黑色，覆盖全屏 |
| 游戏容器宽度 | `400px` | 与 Canvas 等宽 |
| 游戏容器位置 | 水平居中，垂直居中 | `display: flex; justify-content: center; align-items: center; min-height: 100vh` |
| 分数面板高度 | `40px` | 固定高度 |
| 分数面板与画布间距 | `0px` | 紧贴画布上方 |
| 页面最小支持宽度 | `480px` | 低于此宽度不做适配 |

## 三、分数面板（HTML 元素）

分数面板位于 Canvas 上方，是独立的 HTML 元素，不在 Canvas 内绘制。

```
+----------------------------------------------+
|  分数: 0                          最高分: 0   |
+----------------------------------------------+
宽度: 400px  高度: 40px
```

| 元素 | 位置 | 字号 | 字体 | 颜色 | 说明 |
|------|------|------|------|------|------|
| "分数: {N}" | 左侧，左对齐 | `20px` | Arial, sans-serif | `#ffffff` | 实时更新，初始为 0 |
| "最高分: {N}" | 右侧，右对齐 | `20px` | Arial, sans-serif | `#ffffff` | 从 localStorage 读取 |

### 分数面板样式

| 属性 | 值 |
|------|-----|
| 背景色 | `transparent`（透明，与页面背景融合） |
| 布局 | `display: flex; justify-content: space-between; align-items: center` |
| 内边距 | `padding: 8px 0` |
| 宽度 | `400px` |

## 六、游戏元素绘制规格

### 6.1 蛇

| 属性 | 值 |
|------|-----|

## 七、三个状态界面设计

### 7.1 开始界面

画布显示网格背景，中央显示标题和提示文字。无蛇、无食物。

```
+----------------------------------------------+
|  分数: 0                          最高分: 0   |  ← HTML 分数面板
+----------------------------------------------+
|                                              |
|                                              |
|                                              |
|               贪 吃 蛇                        |  ← 字号 48px，白色
|                                              |
|           按空格键开始游戏                      |  ← 字号 20px，白色
|                                              |
|                                              |
|                                              |
+----------------------------------------------+
```

| 元素 | 字号 | 字体 | 颜色 | 位置（Canvas 内坐标） |
|------|------|------|------|----------------------|
| "贪吃蛇" | `48px` | Arial, sans-serif | `#ffffff` | 水平居中，Y = 160px（画布高度 40%） |
| "按空格键开始游戏" | `20px` | Arial, sans-serif | `#ffffff` | 水平居中，Y = 220px（标题下方 60px） |

文字绘制方式：`ctx.textAlign = 'center'; ctx.textBaseline = 'middle'`，X 坐标 = `canvas.width / 2 = 200`。

### 7.2 游戏进行中界面

标题和提示文字消失。画布内只有网格背景、蛇和食物。分数面板实时更新。

```
+----------------------------------------------+
|  分数: 30                        最高分: 120  |  ← 实时更新
+----------------------------------------------+
|  · · · · · · · · · · · · · · · · · · · ·     |
|  · · · · · · · · · · · · · · · · · · · ·     |
|  · · · · · · · · · · · · · · · · · · · ·     |
|  · · · · ■ ■ ■ ■ · · · · · · · · · · ·     |  ← 蛇（绿色方块）
|  · · · · · · · · · · · · · · · · · · · ·     |
|  · · · · · · · · · · · ● · · · · · · · ·    |  ← 食物（红色圆形）
|  · · · · · · · · · · · · · · · · · · · ·     |
+----------------------------------------------+
```

此状态下无额外 UI 元素覆盖，画布只绘制：
1. 网格背景
2. 蛇（蛇头深绿 + 蛇身绿色）
3. 食物（红色圆形）

### 7.3 游戏结束界面

画布上覆盖半透明遮罩，显示结束信息。蛇和食物保持最后位置不动（在遮罩下可隐约看到）。

```
+----------------------------------------------+
|  分数: 80                        最高分: 120  |  ← 分数面板保持
+----------------------------------------------+
| ╔════════════════════════════════════════════╗ |
| ║                                            ║ |
| ║                                            ║ |
| ║             游 戏 结 束                     ║ |  ← 字号 36px，白色
| ║                                            ║ |
| ║           最终分数: 80                      ║ |  ← 字号 24px，白色
| ║                                            ║ |
| ║         按空格键重新开始                     ║ |  ← 字号 18px，白色
| ║                                            ║ |
| ╚════════════════════════════════════════════╝ |
+----------------------------------------------+
  ↑ 遮罩层 rgba(0,0,0,0.5) 覆盖整个画布
```

| 元素 | 字号 | 字体 | 颜色 | 位置（Canvas 内坐标） |
|------|------|------|------|----------------------|
| 遮罩层 | — | — | `rgba(0, 0, 0, 0.5)` | 覆盖整个画布 `fillRect(0, 0, 400, 400)` |
| "游戏结束" | `36px` | Arial, sans-serif | `#ffffff` | 水平居中，Y = 140px |
| "最终分数: {N}" | `24px` | Arial, sans-serif | `#ffffff` | 水平居中，Y = 200px |
| "按空格键重新开始" | `18px` | Arial, sans-serif | `#ffffff` | 水平居中，Y = 260px |

#### 通关特殊情况

当蛇填满整个 20×20 = 400 格网格时（理论极限），显示通关界面：

| 元素 | 与游戏结束界面的差异 |
|------|---------------------|
| 标题文字 | "恭喜通关" 替代 "游戏结束" |
| 其余元素 | 不变 |

## 八、交互行为

| 用户操作 | 触发条件 | 预期结果 |
|----------|----------|----------|
| 按空格键 | 开始界面状态 | 标题和提示消失，蛇出现在画布中央向右移动，食物随机生成 |
| 按方向键 ↑ | 游戏进行中，当前方向非向下 | 蛇下一帧向上移动 |
| 按方向键 ↓ | 游戏进行中，当前方向非向上 | 蛇下一帧向下移动 |
| 按方向键 ← | 游戏进行中，当前方向非向右 | 蛇下一帧向左移动 |
| 按方向键 → | 游戏进行中，当前方向非向左 | 蛇下一帧向右移动 |
| 按反方向键 | 游戏进行中 | 忽略操作，方向不变 |
| 快速连续按键 | 游戏进行中 | 每帧只处理一次方向变更，防止掉头 |
| 按空格键 | 游戏结束状态 | 清除遮罩，重置蛇/分数/食物，游戏重新开始 |
| 蛇头碰食物 | 游戏进行中 | 蛇身 +1 格，分数 +10，新食物随机生成 |
| 蛇头碰墙壁 | 游戏进行中 | 游戏结束，显示遮罩和结束界面 |
| 蛇头碰自身 | 游戏进行中 | 游戏结束，显示遮罩和结束界面 |

## 九、状态覆盖

| 组件/区域 | 开始界面 | 游戏进行中 | 游戏结束 |

| 蛇 | 不显示 | 正常绘制和移动 | 保持最后位置（遮罩下可见） |
| 食物 | 不显示 | 正常绘制 | 保持最后位置（遮罩下可见） |
| 标题文字 | "贪吃蛇" 48px | 不显示 | 不显示 |
| 开始提示 | "按空格键开始游戏" 20px | 不显示 | 不显示 |
| 遮罩层 | 不显示 | 不显示 | `rgba(0,0,0,0.5)` 覆盖全画布 |
| 结束标题 | 不显示 | 不显示 | "游戏结束" 36px |
| 最终分数 | 不显示 | 不显示 | "最终分数: {N}" 24px |
| 重新开始提示 | 不显示 | 不显示 | "按空格键重新开始" 18px |

## 十、数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| 当前分数 | 游戏内存状态 | 每吃一个食物 +10，初始为 0 |
| 最高分 | `localStorage.getItem("snakeHighScore")` | 页面加载时读取，不可用时默认 0 |
| — | — | localStorage 不可用（如隐私模式）时，UI 无任何错误提示，最高分始终显示 0，游戏正常运行 |
| 蛇的位置 | 游戏内存状态 | 坐标数组，每 200ms 更新 |
| 食物位置 | 游戏内存状态 | 随机生成，不与蛇身重叠 |
| 游戏状态 | 游戏内存状态 | 三种：`start` / `playing` / `gameover` |
| 游戏速度 | 固定值 | 每 200ms 移动一格，不随分数变化 |

## 十一、响应式适配

| 条件 | 处理方式 |
|------|----------|
| 视口宽度 ≥ 480px | 游戏容器居中显示，正常布局 |
| 视口宽度 < 480px | 不做适配（PRD 明确最小支持 480px） |
| 视口高度不足 | 页面可滚动，游戏容器不缩放 |

画布固定 400×400px，不做缩放。页面居中方式使用 Flexbox，确保在不同屏幕尺寸下居中。
