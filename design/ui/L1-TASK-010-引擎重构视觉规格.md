## 六、粒子特效规格

### 6.1 吃食物粒子

| 属性 | 值 | 来源 |
|------|-----|------|
| 颜色 | `rgba(255, 107, 107, {alpha})`（粉红色） | `particle.js` render() |
| 粒子数量 | 6 + random(0~2) = 6~8 个 | `particle.js` spawn() |
| 粒子半径 | 3px | `particle.js` render() |
| 生命周期 | 15 帧 | `particle.js` spawn() life=15 |
| 初始透明度 | 1.0 | `particle.js` spawn() alpha=1 |
| 透明度衰减 | `alpha = life / 15`（线性衰减） | `particle.js` update() |
| 发射速度 | 2 + random(0~2) = 2~4 px/帧 | `particle.js` spawn() |
| 发射角度 | 均匀分布 360°，每个粒子加 random(0~0.5) 弧度偏移 | `particle.js` spawn() |
| 发射原点 | 食物所在格子中心 `(gridX * CELL_SIZE + CELL_SIZE/2, gridY * CELL_SIZE + CELL_SIZE/2)` | `particle.js` spawn() |
| 运动方式 | 匀速直线，无重力/摩擦 | `particle.js` update() |

### 6.2 游戏结束粒子

与吃食物粒子使用相同的 `ParticleSystem.spawn()` 方法，参数一致。

> 引擎重构时，可用引擎内置粒子系统替代，但必须保证视觉效果一致：粉红色、6~8 个、向外扩散、线性淡出。

## 十二、引擎重构注意事项

1. 引擎内部坐标系保持 600×600px，通过引擎缩放或 CSS 适配屏幕
2. 所有颜色值、尺寸参数必须与本文档一致，不可自行调整
3. 粒子系统可用引擎内置粒子替代，但视觉效果（颜色、数量、扩散、淡出）必须一致
4. HTML 层元素（分数面板、静音按钮、虚拟方向键）保留为 DOM，不迁入引擎 UI 系统
5. Canvas `touch-action: none` 必须保留，防止触摸滚动/缩放
6. 渲染层级顺序不可改变
