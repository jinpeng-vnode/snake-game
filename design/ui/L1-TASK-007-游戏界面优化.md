## 三、虚拟方向键

### 3.1 HTML 结构

```html
<!-- 画布下方，game-container 内 -->
<div id="dpad" class="dpad-container">
    <button class="dpad-btn dpad-up" data-dir="up" aria-label="上">▲</button>
    <div class="dpad-middle">
        <button class="dpad-btn dpad-left" data-dir="left" aria-label="左">◀</button>
        <div class="dpad-center"></div>
        <button class="dpad-btn dpad-right" data-dir="right" aria-label="右">▶</button>
    </div>
    <button class="dpad-btn dpad-down" data-dir="down" aria-label="下">▼</button>
</div>
```

### 3.2 布局规格

| 属性 | 值 | 说明 |
|------|-----|------|
| 容器布局 | `flex-direction: column; align-items: center` | 十字布局，上下左右 |
| 容器间距 | `margin-top: 16px` | 与画布间距 |
| 默认显示 | `display: none` | PC 端隐藏 |
| 移动端显示 | `@media (max-width: 767px) { display: flex }` | 屏幕宽度 < 768px 时显示 |

### 3.3 按钮规格

| 属性 | 值 |
|------|-----|
| 尺寸 | `clamp(48px, 12vw, 64px)` 宽高相等，正方形 |
| 背景色 | `rgba(255, 255, 255, 0.1)` |
| 按下背景色 | `rgba(255, 255, 255, 0.3)` |
| 边框 | `1px solid rgba(255, 255, 255, 0.2)` |
| 圆角 | `8px` |
| 字号 | `clamp(18px, 4vw, 24px)` |
| 字色 | `#ffffff` |
| 中心占位 | 与按钮等大，无背景无边框（纯占位） |
| 行间距 | `dpad-middle` 内三个元素 `gap: 4px`；上/中/下行 `gap: 4px` |

### 3.4 交互行为

| 用户操作 | 触发事件 | 预期结果 |
|----------|----------|----------|
| 点击/触摸 ▲ | `touchstart`（优先）/ `click` | 设置蛇方向为上（当前方向为下时忽略） |
| 点击/触摸 ▼ | 同上 | 设置蛇方向为下（当前方向为上时忽略） |
| 点击/触摸 ◀ | 同上 | 设置蛇方向为左（当前方向为右时忽略） |
| 点击/触摸 ▶ | 同上 | 设置蛇方向为右（当前方向为左时忽略） |

> 使用 `touchstart` 而非 `click`，避免移动端 300ms 延迟。按钮加 `touch-action: manipulation` 禁止双击缩放。

### 3.5 状态覆盖

| 状态 | 显示 |
|------|------|
| 屏幕 ≥ 768px | 隐藏（`display: none`） |
| 屏幕 < 768px + 游戏进行中 | 正常显示，可交互 |
| 屏幕 < 768px + 暂停/结束 | 正常显示，点击无效（游戏非 playing 状态时忽略输入） |

## 五、暂停界面

### 5.1 触发条件

- 按 `ESC` 或 `P` 键（游戏进行中）
- 页面失焦（`visibilitychange` 事件，`document.hidden === true`）

### 5.2 Canvas 绘制规格

```
+----------------------------------------------+
| ╔════════════════════════════════════════════╗ |
| ║                                            ║ |
| ║                                            ║ |
| ║              已 暂 停                       ║ |  ← 字号 36px，白色
| ║                                            ║ |
| ║        按 ESC 或 P 键继续                   ║ |  ← 字号 18px，白色
| ║                                            ║ |
| ╚════════════════════════════════════════════╝ |
+----------------------------------------------+
  ↑ 遮罩层 rgba(0, 0, 0, 0.5) 覆盖整个画布
```

| 元素 | 字号 | 颜色 | 位置（Canvas 内） |
|------|------|------|------------------|
| 遮罩层 | — | `rgba(0, 0, 0, 0.5)` | `fillRect(0, 0, canvasW, canvasH)` |
| "已暂停" | `36px` Arial | `#ffffff` | 水平居中，Y = `canvasH * 0.4` |
| "按 ESC 或 P 键继续" | `18px` Arial | `#ffffff` | 水平居中，Y = `canvasH * 0.4 + 50px` |

> 移动端提示文字改为 "点击屏幕继续"（根据 `window.innerWidth < 768` 判断）。

### 5.3 状态覆盖

| 状态 | 暂停界面 |
|------|----------|
| 游戏进行中 | 不显示 |
| 暂停中 | 显示遮罩 + 文字，蛇/食物/墙壁在遮罩下可见 |
| 开始/结束 | 不显示（各自有独立遮罩） |

### 5.4 暂停时冻结规则

- 特殊食物倒计时暂停
- 特殊效果持续时间暂停
- 蛇不移动
- 粒子动画暂停

## 六、多种食物外观

### 6.1 食物类型绘制规格

所有食物绘制在 `CELL_SIZE`（20px）网格内，居中绘制。

| 食物类型 | 颜色 | 形状 | 绘制方式 | 尺寸 |
|----------|------|------|----------|------|
| 普通 | `#F44336`（红色） | 圆形 | `arc(cx, cy, r, 0, 2π)` | 半径 8px |
| 加速 | `#FF9800`（橙色） | 菱形 | 四点连线：上中、右中、下中、左中 | 对角线 16px |
| 减速 | `#2196F3`（蓝色） | 三角形 | 三点连线：上中、左下、右下 | 底边 16px，高 14px |
| 双倍得分 | `#FFD700`（金色） | 五角星 | 5 个外顶点 + 5 个内顶点交替连线 | 外径 9px，内径 4px |
| 缩短 | `#9C27B0`（紫色） | 方形 | `fillRect` | 14×14px，居中 |

### 6.2 绘制坐标计算

```
格子左上角: (gridX * CELL_SIZE, gridY * CELL_SIZE)
格子中心:   (gridX * CELL_SIZE + CELL_SIZE/2, gridY * CELL_SIZE + CELL_SIZE/2)
```

### 6.3 各形状绘制细节

**圆形（普通食物）：**
- 圆心 = 格子中心
- 半径 = 8px
- `ctx.beginPath(); ctx.arc(cx, cy, 8, 0, Math.PI * 2); ctx.fill();`

**菱形（加速食物）：**
- 四个顶点相对格子中心偏移：上(0, -8)、右(8, 0)、下(0, 8)、左(-8, 0)
- `moveTo → lineTo × 3 → closePath → fill`

**三角形（减速食物）：**
- 三个顶点相对格子中心：上(0, -7)、左下(-8, 7)、右下(8, 7)
- `moveTo → lineTo × 2 → closePath → fill`

**五角星（双倍得分食物）：**
- 外径 9px，内径 4px，5 个角
- 从顶部开始（-π/2），每 π/5 交替外/内顶点，共 10 个点
- `moveTo → lineTo × 9 → closePath → fill`

**方形（缩短食物）：**
- 左上角 = 格子中心 - 7px
- `ctx.fillRect(cx - 7, cy - 7, 14, 14);`

## 七、墙壁边界视觉

### 7.1 绘制规格

画布四周内边缘绘制渐变暗色条，营造墙壁围栏感。

| 属性 | 值 |
|------|-----|
| 边界宽度 | 4px（画布内侧） |
| 颜色 | `#3a3a5c`（灰紫色，比画布背景 `#1a1a2e` 亮） |
| 绘制方式 | 四条矩形：上/下/左/右 |

### 7.2 四条矩形坐标

| 边 | x | y | width | height |
|----|---|---|-------|--------|
| 上 | 0 | 0 | canvasW | 4 |
| 下 | 0 | canvasH - 4 | canvasW | 4 |
| 左 | 0 | 0 | 4 | canvasH |
| 右 | canvasW - 4 | 0 | 4 | canvasH |

### 7.3 渲染顺序

墙壁在背景之后、食物/蛇之前绘制：
```
背景 → 网格线 → 墙壁边界 → 食物 → 蛇 → 粒子 → 效果指示器 → 遮罩（暂停/结束）
```

## 八、效果状态指示器

### 8.1 位置与布局

| 属性 | 值 |
|------|-----|
| 位置 | Canvas 内部，顶部居中 |
| Y 坐标 | 12px（距画布顶部） |
| 布局 | 多个效果标签水平排列，居中对齐，间距 8px |

### 8.2 单个效果标签规格

```
+------------------+
| ⚡ 加速 4s       |
+------------------+
```

| 属性 | 值 |
|------|-----|
| 背景色 | 半透明黑 `rgba(0, 0, 0, 0.5)` |
| 圆角 | 4px |
| 内边距 | 水平 6px，垂直 2px |
| 字号 | `12px` Arial |
| 字色 | 与对应食物颜色一致 |
| 图标 | 文字前缀（见下表） |

### 8.3 效果类型显示

| 效果 | 前缀 | 文字颜色 | 显示格式 |
|------|------|----------|----------|
| 加速 | ⚡ | `#FF9800` | `⚡ 加速 {N}s` |
| 减速 | 🐢 | `#2196F3` | `🐢 减速 {N}s` |
| 双倍得分 | ✨ | `#FFD700` | `✨ 双倍 {N}s` |

> `{N}` 为剩余秒数，向上取整（`Math.ceil(remaining / 1000)`）。

### 8.4 绘制方式

1. 计算所有生效效果标签的总宽度（每个标签宽度 = `ctx.measureText` 测量 + 12px 内边距）
2. 起始 X = `(canvasW - 总宽度) / 2`
3. 逐个绘制：先画圆角矩形背景，再画文字

### 8.5 状态覆盖

| 状态 | 显示 |
|------|------|
| 无生效效果 | 不显示任何标签 |
| 有 1 个效果 | 居中显示 1 个标签 |
| 有多个效果 | 水平排列，居中 |
| 暂停中 | 保持显示（在遮罩下可见） |

## 九、食物限时闪烁效果

### 9.1 闪烁规则

| 条件 | 表现 |
|------|------|
| 特殊食物剩余时间 > 3s | 正常显示，不闪烁 |
| 特殊食物剩余时间 ≤ 3s | 闪烁：每 300ms 切换显示/隐藏 |
| 普通食物 | 无限时，不闪烁 |

### 9.2 闪烁实现规格

- 闪烁周期：300ms（显示 150ms → 隐藏 150ms）
- 判断方式：`Date.now() % 300 < 150` 时绘制食物，否则跳过绘制
- 闪烁期间食物仍可被吃到（碰撞检测不受影响）

### 9.3 视觉效果

闪烁时食物在「完全可见」和「完全不可见」之间切换，不做渐变透明度。

## 十一、移动端适配补充

### 11.1 Canvas 触屏

| 属性 | 值 | 说明 |
|------|-----|------|
| `touch-action` | `none` | 禁止浏览器默认触摸行为（滚动/缩放） |
| 滑动阈值 | 30px | 滑动距离 ≥ 30px 触发方向变更 |
| 滑动判定 | 取水平/垂直位移较大的轴 | 防止斜向滑动误触 |

### 11.2 响应式断点

| 条件 | 变化 |
|------|------|
| 宽度 < 768px | 显示虚拟方向键 |
| 宽度 ≥ 768px | 隐藏虚拟方向键 |
| 宽度 < 768px | 暂停提示文字改为 "点击屏幕继续" |
| 宽度 ≥ 768px | 暂停提示文字为 "按 ESC 或 P 键继续" |

### 11.3 游戏容器自适应

已有规格（`L1-TASK-002` 中定义）：
- 容器宽度 `min(90vw, 90vh)`，`max-width: 1000px`
- Canvas `width: 100%; height: auto` CSS 缩放
