# L1-TASK-009 贪吃蛇视觉升级 UI 规格

## 一、页面信息
- 文件：`index.html` + `game.js`
- 类型：Canvas 游戏界面
- 技术：原生 Canvas 2D API

## 二、画布自适应规格

### 尺寸计算
- **视口检测**：取 `Math.min(window.innerWidth, window.innerHeight)` 作为基准
- **画布尺寸范围**：400px - 800px
- **计算公式**：
  ```
  基准尺寸 = Math.min(视口宽度, 视口高度) * 0.8
  画布尺寸 = Math.max(400, Math.min(800, Math.floor(基准尺寸 / 20) * 20))
  ```
  （确保是 20 的倍数，保持网格对齐）
- **网格数量**：固定 20×20
- **格子尺寸**：画布尺寸 / 20（动态计算）

### 响应式行为
- **初始化时**：计算并设置画布尺寸
- **窗口缩放时**：监听 `window.resize` 事件，重新计算画布尺寸并重绘
- **防抖处理**：resize 事件防抖 200ms

## 三、蛇的视觉规格

### 蛇头绘制参数
- **形状**：圆角矩形
- **尺寸**：格子尺寸 - 2px（留 1px 间隙）
- **圆角半径**：格子尺寸 * 0.3
- **基础颜色**：`#4CAF50`

### 眼睛绘制参数（根据方向动态调整）
- **眼睛形状**：圆形
- **眼睛半径**：格子尺寸 * 0.08
- **眼睛颜色**：`#000000`
- **眼睛位置**（以格子中心为原点，单位为格子尺寸的比例）：

| 方向 | 左眼 X | 左眼 Y | 右眼 X | 右眼 Y |
|------|--------|--------|--------|--------|
| UP | -0.15 | -0.2 | 0.15 | -0.2 |
| DOWN | -0.15 | 0.2 | 0.15 | 0.2 |
| LEFT | -0.2 | -0.15 | -0.2 | 0.15 |
| RIGHT | 0.2 | -0.15 | 0.2 | 0.15 |

### 蛇身渐变色规格
- **渐变方式**：从蛇头到蛇尾线性插值
- **起始色（蛇头）**：`#4CAF50` (RGB: 76, 175, 80)
- **结束色（蛇尾）**：`#81C784` (RGB: 129, 199, 132)
- **插值公式**：
  ```
  对于第 i 段（i=0 为蛇头）：
  progress = i / (总段数 - 1)
  R = 76 + (129 - 76) * progress
  G = 175 + (199 - 175) * progress
  B = 80 + (132 - 80) * progress
  颜色 = rgb(R, G, B)
  ```
- **形状**：圆角矩形，圆角半径 = 格子尺寸 * 0.2

## 四、食物（苹果）视觉规格

### 苹果主体
- **形状**：圆形
- **半径**：格子尺寸 * 0.4
- **位置**：格子中心
- **颜色**：`#F44336` (红色)

### 高光
- **形状**：圆形
- **半径**：格子尺寸 * 0.12
- **位置**：相对苹果中心偏移 (-0.15, -0.15)（单位为格子尺寸）
- **颜色**：`rgba(255, 255, 255, 0.6)`

### 茎
- **形状**：矩形
- **宽度**：格子尺寸 * 0.08
- **高度**：格子尺寸 * 0.15
- **位置**：苹果顶部中心，Y 偏移 -0.4（单位为格子尺寸）
- **颜色**：`#8B4513` (棕色)

### 叶子
- **形状**：椭圆
- **宽度**：格子尺寸 * 0.2
- **高度**：格子尺寸 * 0.12
- **位置**：茎的右侧，X 偏移 0.1，Y 偏移 -0.35（单位为格子尺寸）
- **颜色**：`#4CAF50` (绿色)
- **旋转角度**：30 度

## 五、背景视觉规格

### 棋盘格背景
- **格子类型**：交替色棋盘格
- **浅色格**：`#1a1a2e`
- **深色格**：`#16213e`
- **规则**：`(x + y) % 2 === 0` 时使用浅色，否则使用深色

### 网格线（移除）
- 原有的网格线不再绘制，改用棋盘格区分格子

## 六、UI 文字视觉规格

### 分数面板（HTML 元素）
- **容器宽度**：与画布宽度一致（动态）
- **字体**：`'Arial', sans-serif`
- **字号**：画布尺寸 / 20（动态计算，最小 16px，最大 32px）
- **颜色**：`#ffffff`
- **布局**：flex 两端对齐

### 游戏开始界面（Canvas 绘制）
- **标题 "贪吃蛇"**：
  - 字号：画布尺寸 / 8.33（约 48px @ 400px 画布）
  - 颜色：`#ffffff`
  - 位置：画布中心，Y 偏移 -40px
- **提示 "按空格键开始游戏"**：
  - 字号：画布尺寸 / 20（约 20px @ 400px 画布）
  - 颜色：`#ffffff`
  - 位置：画布中心，Y 偏移 +20px

### 游戏结束界面（Canvas 绘制）
- **遮罩**：`rgba(0, 0, 0, 0.5)` 覆盖整个画布
- **标题 "游戏结束"**：
  - 字号：画布尺寸 / 11.11（约 36px @ 400px 画布）
  - 颜色：`#ffffff`
  - 位置：画布中心，Y 偏移 -60px
- **最终分数**：
  - 字号：画布尺寸 / 16.67（约 24px @ 400px 画布）
  - 颜色：`#ffffff`
  - 位置：画布中心
- **重新开始提示**：
  - 字号：画布尺寸 / 22.22（约 18px @ 400px 画布）
  - 颜色：`#ffffff`
  - 位置：画布中心，Y 偏移 +60px

## 七、状态覆盖

| 状态 | 视觉表现 |
|------|----------|
| 准备开始 | 棋盘格背景 + 开始界面文字 |
| 游戏中 | 棋盘格背景 + 蛇（渐变色+眼睛）+ 苹果 + 分数面板 |
| 游戏结束 | 游戏中画面 + 半透明遮罩 + 结束界面文字 |
| 通关 | 游戏中画面 + 半透明遮罩 + 通关界面文字（同结束界面，标题改为"恭喜通关"） |

## 八、交互行为（无变化）

| 用户操作 | 预期结果 |
|----------|----------|
| 方向键 | 改变蛇的移动方向 |
| 空格键 | 开始游戏 / 重新开始 |
| 窗口缩放 | 画布自适应调整尺寸并重绘 |

## 九、实现约束

- **纯原生实现**：不引入任何第三方库（如 PixiJS、Phaser）
- **逻辑不变**：游戏逻辑、碰撞检测、分数计算完全不变
- **模块内改造**：所有改动在 Renderer 模块内部，不影响其他模块接口
- **性能要求**：resize 防抖，避免频繁重绘

## 十、设计原则

- **比例化设计**：所有尺寸参数以格子尺寸的比例表示，确保在不同画布尺寸下视觉一致
- **Q 弹风格**：圆角、渐变色、眼睛动画营造可爱风格
- **视觉层次**：棋盘格背景 → 蛇身 → 食物，层次分明
- **适配优先**：优先保证 400px-800px 范围内的视觉效果
