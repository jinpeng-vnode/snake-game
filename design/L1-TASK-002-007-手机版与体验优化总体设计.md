# L1 TASK-002~006 手机版与体验优化 总体设计文档

> 覆盖 Issue: #31(TASK-002) #32(TASK-003) #33(TASK-004) #34(TASK-005) #35(TASK-006)
> 本项目为纯前端单文件架构（game.js + index.html），所有任务修改同一文件，故合并设计。

---

## 一、需求摘要

将贪吃蛇游戏从纯 PC 键盘操控升级为：
1. **#31 TASK-002** 手机触屏适配 + 虚拟方向键 + 响应式布局（P0）
2. **#32 TASK-003** Web Audio API 音效系统（P1）
3. **#33 TASK-004** 暂停功能 + ESC/P/WASD 键位扩展（P1）
4. **#34 TASK-005** 粒子特效接入 + 墙壁边界视觉（P1）
5. **#35 TASK-006** 多种食物类型 + 特殊效果系统（P1，L2 依赖 L1）

---

## 二、方案选择

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| A | 保持单文件 game.js，按模块对象扩展 | 零构建成本，与现有架构一致，PRD 明确要求单文件 | 文件会增长到 ~1500 行 |
| B | 拆分为多个 ES Module 文件 | 代码组织更清晰 | 违反 PRD"保持单文件"要求，需引入构建工具 |

**选择方案 A，理由：PRD 明确要求保持 game.js + index.html 单文件结构，且当前模块对象模式已足够清晰。**


唯一例外：Renderer 需要读取 FoodType 常量来决定绘制形状。

## 八、错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| AudioContext 创建失败（旧浏览器） | SoundManager 静默降级，所有播放方法变为空操作 |
| localStorage 不可用 | 静音状态默认 false，不持久化，静默忽略 |
| 触屏事件不支持 | 不注册触屏监听，不影响键盘操控 |
| 虚拟方向键 DOM 不存在 | initVirtualDpad 内做 null 检查后跳过 |
| requestAnimationFrame 不支持 | 降级为 setTimeout（现有代码已用 rAF，极端情况忽略） |

## 十一、开发者注意事项

1. **保持单文件架构**：所有代码在 game.js 中，不拆分文件
2. **模块间通过 Game 协调**：新模块（SoundManager、EffectManager）不直接调用其他模块，由 Game 在 tick/render 中统一调度
3. **Input.init() 签名变更**：新增第三个参数 `onPause`，TASK-002 和 TASK-004 都会修改此函数，注意合并
4. **Score.add() 签名变更**：从无参改为 `add(baseScore, multiplier)`，TASK-006 实现时需同步修改 Game.tick() 中的调用
5. **Food.spawn() 兼容**：TASK-006 扩展 Food 模块前，L1 阶段 Food 保持原有接口不变
6. **渲染顺序**：背景 → 墙壁 → 食物 → 蛇 → 粒子 → 效果指示 → 遮罩（暂停/结束）
7. **触屏防抖**：canvas 添加 `touch-action: none` CSS，防止浏览器默认滑动行为
8. **AudioContext 策略**：必须在用户交互（click/touchstart）后才创建 AudioContext，否则浏览器会阻止
9. **暂停时冻结一切**：暂停状态下 EffectManager 和 Food 的计时器都不更新（不调用 update）
10. **CELL_SIZE 和 CANVAS_SIZE 保持不变**：响应式通过 CSS `width:100%` 实现缩放，JS 中画布逻辑尺寸不变
