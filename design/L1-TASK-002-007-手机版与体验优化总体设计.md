# L1 TASK-002~006 手机版与体验优化 总体设计文档

> 覆盖 Issue: #31(TASK-002) #32(TASK-003) #33(TASK-004) #34(TASK-005) #35(TASK-006)

---

## 一、需求摘要

将贪吃蛇游戏从纯 PC 键盘操控升级为：
1. **#31 TASK-002** 手机触屏适配 + 虚拟方向键 + 响应式布局（P0）
2. **#32 TASK-003** Web Audio API 音效系统（P1）
3. **#33 TASK-004** 暂停功能 + ESC/P/WASD 键位扩展（P1）
4. **#34 TASK-005** 粒子特效接入 + 墙壁边界视觉（P1）
5. **#35 TASK-006** 多种食物类型 + 特殊效果系统（P1，L2 依赖 L1）

---

## 二、方案选择

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| A | 保持单文件 game.js | 零构建成本 | 文件膨胀到 ~1500 行，并行开发冲突严重 |
| B | 拆分为 ES Module 多文件，用 `<script type="module">` 加载 | 每个模块独立文件，并行开发零冲突，职责清晰 | 需调整 index.html 入口 |

**选择方案 B，理由：多文件结构让每个任务修改独立文件，L1 四个任务真正可并行开发无冲突。现代浏览器原生支持 ES Module，无需构建工具。**

### 拆分原则
- 原 game.js 中每个模块对象提取为独立文件，用 `export default` 导出
- 常量统一放 constants.js，各模块 `import` 引用
- index.html 的 `<script src="game.js">` 改为 `<script type="module" src="js/main.js">`
- 原 game.js 保留为空文件或删除（由前端开发者决定）
